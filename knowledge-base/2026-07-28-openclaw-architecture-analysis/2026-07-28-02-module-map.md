# 02 — 模块地图与目录职责

依据 AGENTS.md "Map" 段与实际目录分布,核心模块分层如下。

## 顶层目录职责

| 目录 | 职责 | 边界规则 |
|---|---|---|
| `src/` | 核心 TS 运行时 | 保持插件无关,不内嵌 bundled id/defaults/policy |
| `src/gateway/` | Gateway 服务器实现 | HTTP/WS server、auth、cron、reload、boot |
| `src/agents/` | Agent 命令运行时 | `agent-command.ts`、`agent-run-terminal-outcome.ts` |
| `src/channels/` | 通道核心实现 | **插件作者不应直接 import**,需通过 `openclaw/plugin-sdk/*` |
| `src/plugins/` | 插件发现/加载/注册 | discovery + manifest + registry + runtime |
| `src/plugin-sdk/` | 对外 SDK 边界 | 数百个 `*-runtime.ts` 懒加载接缝 |
| `src/state/` | SQLite 状态层 | 共享 state DB + per-agent DB |
| `src/config/` | 配置加载/迁移/校验 | `io.load.ts`、`paths.ts` |
| `packages/gateway-protocol/` | 协议契约独立子包 | TypeBox schemas + validators + migration-api |
| `extensions/` | 内部/外部插件实现 | 各渠道(telegram/discord/...) + 工具 |
| `ui/` | Control UI 前端 | 独立子包 |
| `docs/` | 源文档 | 发布到 `docs.openclaw.ai` |
| `apps/` | 配套应用 | macOS/iOS/Android/Windows Hub |

## 边界硬约束(AGENTS.md "Architecture" 段)

1. **核心保持插件无关**:不内嵌 bundled id、defaults、policy。
2. **插件跨入核心只通过 SDK**:必须经 `openclaw/plugin-sdk/*`、manifest metadata、injected runtime helpers、documented barrels(`api.ts`、`runtime-api.ts`)。
3. **插件 prod 代码禁止**:
   - import 核心 `src/**`
   - import `src/plugin-sdk-internal/**`
   - import 其他插件 `src/**`
   - 相对路径出包
4. **核心/tests 禁止**:深入插件 internals(`extensions/*/src/**`、`onboard.js`),只能用 public barrels、SDK facade、generic contracts。
5. **Owner 边界**:owner 特定行为(检测/onboarding/auth/defaults/provider)放在 owner 插件;核心只暴露 generic seams。
6. **依赖归属随运行时归属**:插件 only 依赖留在插件本地;只有核心 import 或有意 internalized 的 bundled plugin runtime 才放 root dep。

## AGENTS.md 路由 Map

AGENTS.md "Map" 段明确:

```
- Core TS: src/, ui/, packages/; plugins: extensions/; SDK: src/plugin-sdk/*;
  channels: src/channels/*; loader: src/plugins/*; protocol: packages/gateway-protocol/*;
  docs/apps: docs/, apps/.
- Installers: sibling ../openclaw.ai.
- Scoped guides: extensions/, src/{plugin-sdk,channels,plugins,gateway,agents}/,
  packages/, test/helpers*/, docs/, ui/, scripts/.
```

每个 scoped 目录有自己的 AGENTS.md(如 `src/plugins/AGENTS.md`、`src/channels/AGENTS.md`),进入对应子树前必须先读。
