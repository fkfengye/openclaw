# 06 — 通道系统(Channels)

## 6.1 边界

[src/channels/AGENTS.md](file:///d:/DevSpace/person/ai_space/openclaw/src/channels/AGENTS.md) 明确:

> `src/channels/**` is core channel implementation. Plugin authors should not import from this tree directly.

插件作者必须通过 `openclaw/plugin-sdk/*` 使用通道能力。

**通道插件保持 transport-only**(AGENTS.md "Architecture" 段):

> Message/channel plugins stay transport-only. They render portable presentation/actions, enforce transport limits, and map native callback envelopes. They do not own product command trees, plugin/provider policy, or feature-specific menus.

> Portable command UI must use typed presentation actions, not raw string inference. Do not make channels guess that `value` starting with `/` means a native command; core/owner plugins declare command actions, channels map them when supported.

> Raw callback data is transport/private. Approval, command, URL, web-app, and select actions must stay distinguishable before channel encoding so transport adapters do not special-case product strings.

## 6.2 Turn 内核

[src/channels/turn/kernel.ts](file:///d:/DevSpace/person/ai_space/openclaw/src/channels/turn/kernel.ts#L1-L119) 是消息回合的核心。

### Admission 类型(discriminated union)

[src/channels/turn/kernel.ts#L66-L77](file:///d:/DevSpace/person/ai_space/openclaw/src/channels/turn/kernel.ts#L66-L77):

```typescript
const DEFAULT_EVENT_CLASS: ChannelEventClass = {
  kind: "message",
  canStartAgentTurn: true,
};

function isAdmission(value: unknown): value is ChannelTurnAdmission {
  if (!value || typeof value !== "object") {
    return false;
  }
  const kind = (value as { kind?: unknown }).kind;
  return kind === "dispatch" || kind === "observeOnly" || kind === "handled" || kind === "drop";
}
```

四种 admission kind 表达"如何处理这条消息":

| Kind | 含义 |
|---|---|
| `dispatch` | 正常派发给 agent |
| `observeOnly` | 仅观察,不触发 agent turn |
| `handled` | 已处理(如 pairing code 命中),不再走 agent |
| `drop` | 丢弃(如 bot loop 命中、被禁止的内容) |

### 核心导出函数

```typescript
export function dispatchAssembledChannelTurn(params): Promise<ChannelTurnResult>;
```

### Lifecycle 守卫

[kernel.ts#L91-L106](file:///d:/DevSpace/person/ai_space/openclaw/src/channels/turn/kernel.ts#L91-L106):

```typescript
function assertPreparedDispatchLifecycle<TDispatchResult>(
  turn: PreparedChannelTurn<TDispatchResult>,
  turnAdoptionLifecycle: RunChannelTurnParams<unknown>["turnAdoptionLifecycle"],
): void {
  const lifecycle = turn.runDispatchLifecycle;
  if (!lifecycle) {
    throw new Error("runChannelInboundEvent prepared turns must declare runDispatchLifecycle when creating runDispatch");
  }
  if (turnAdoptionLifecycle && lifecycle.turnAdoptionLifecycle !== turnAdoptionLifecycle) {
    throw new Error("runChannelInboundEvent prepared turn runDispatchLifecycle must own the top-level turnAdoptionLifecycle");
  }
}
```

确保 prepared turn 必须声明 `runDispatchLifecycle`,且必须拥有 top-level `turnAdoptionLifecycle`(防止 lifecycle 错配)。

## 6.5 DM 安全默认(README "Security defaults")

[README.md](file:///d:/DevSpace/person/ai_space/openclaw/README.md#L148-L167):

- **DM pairing**(`dmPolicy: "pairing"`):未知发送者收到 pairing code,bot 不处理消息。
- 审批:`openclaw pairing approve <channel> <code>`,加入本地 allowlist。
- 公开 DM 需显式 opt-in:`dmPolicy: "open"` + `"*"` 在 `allowFrom`。
- `openclaw doctor` 可检测危险的 DM 配置。

## 6.6 关键观察

- **Turn 内核用 discriminated union**:`dispatch`/`observeOnly`/`handled`/`drop` 让消息处理策略显式可推理。
- **Lifecycle 守卫**:prepared turn 必须声明 lifecycle,防止错配。
- **持久化投递**:`durable-delivery.ts` 防消息丢失。
- **Bot loop 保护**:`bot-loop-protection.ts` 防止 bot 互相触发死循环。
- **Transport-only 约束**:通道插件不拥有产品命令树,只做传输与映射。
- **DM 安全默认**:pairing 模式作为默认,防止未知发送者触发 agent。
